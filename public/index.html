02 / How we can help

A research question.
A workable path forward.

Focused project work, from a well-defined data problem to a documented software handoff.

01

Remote sensing & geospatial data

Prepare, align and process raster and spatial datasets for research. Define the study area, check coordinate and height references, and make the processing repeatable.

  • Raster processing
  • Coastal & environmental workflows
  • Batch automation

Typical deliverablesProcessed datasets, reusable scripts, quality checks and a methods note.

02

Scientific software development

Turn a research method or an existing script into a tool others can use. Build command-line workflows, desktop interfaces, data utilities and research plugins.

  • Python & TypeScript
  • GUI / CLI tools
  • Testing & documentation

Typical deliverablesSource code, an agreed setup or build, tests and usage documentation.

03

AI-assisted research applications

Scope and prototype useful AI features around documents and scientific tools. PaperPilot is an existing example; Claude API integration for geospatial workflows is being planned and evaluated.

  • Document workflows
  • Model API integration
  • Evaluation & human review

Engagement scopeA defined prototype, documented data handling and evaluation against agreed examples.

03 / Working together

Small scope. Clear handoff.

Start with a concrete question and a representative sample. Agree on what success means before expanding the work.

01 / Understand

Define the question.

Discuss your data, constraints and expected outputs. Identify what is feasible and what needs investigation.

02 / Build & check

Work on a small example.

Develop the workflow on representative data. Review assumptions, edge cases and the resulting outputs together.

03 / Deliver

Make it repeatable.

Hand over the agreed code, results and documentation so your team can understand and continue the work.

A few practical questions.

Can we start with a small task?+

Yes. A narrowly defined processing step, software utility or feasibility study is a useful place to start. Scope and terms are discussed before work begins.

Are the projects available to try?+

CoastTideX source and documentation are public. PaperPilot v1.0.1 has a published Zotero add-on package. Each project page links to the relevant repository and setup instructions.

Can an AI feature be part of a project?+

Yes. We can scope an AI-assisted document or tool workflow and evaluate it against representative examples. Provider access, data handling and human review need to be agreed. PaperPilot offers an existing example; future Claude integration is in planning and evaluation.
