A focused technical practice.

HaoHorizon is the working name of Yuhao Wang’s independent studio, operated in the United States. Its focus is helping researchers and small teams turn data and methods into repeatable workflows and usable software.

The intended business includes scoped remote sensing data-processing work, scientific software development and research application prototypes. Project requirements, deliverables and terms are agreed directly before an engagement begins.

Yuhao develops CoastTideX, a coastal tide and vertical-datum toolkit, and PaperPilot, a Zotero reading assistant. Their public repositories provide a view of the code, documentation and development work.

HaoHorizon brings this geospatial and software practice under a straightforward studio identity. Initial priorities are remote sensing data processing and scientific software development.

How the work is approached.

  • Define the inputs and assumptions. Coordinate references, height references, data quality and study boundaries should be explicit.
  • Start with a representative sample. Check the method on a bounded example before committing to a larger run.
  • Keep the workflow inspectable. Prefer understandable code, useful tests and documentation that helps the next person.
  • Evaluate AI in context. Use models for bounded assistance and review their outputs against the original documents or scientific tools.

Studio and product status.

HaoHorizon is currently an unincorporated independent studio operated by Yuhao Wang. Its public technical work includes CoastTideX and PaperPilot, both available under the MIT source license.

Claude API integration is in planning and evaluation. It is a proposed development direction, rather than an available feature of the current PaperPilot release.
