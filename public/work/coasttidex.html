The research question.

Coastal analyses often combine tide levels, elevation rasters and observations with different vertical references. Comparing them without understanding those references can produce misleading results.

CoastTideX is developed for coastal and intertidal workflows that need a clear relationship between tide simulation and elevation data. It provides a practical toolchain for configuring, running and inspecting those steps.

What the toolkit does.

Tide simulationAstronomical tide simulation using the FES2022b model and its native unstructured mesh.
Height referencesWorkflows linking mean sea level, EGM2008 and WGS84 elevation references, with documented MDT and geoid assumptions.
Coastal raster workflowsTools for DEM preparation, tidal inundation and exposure analyses under the configured scientific assumptions.
Batch processingA batch DEM conversion workflow with resume support and processing manifests.
Usable interfacesDesktop GUI and command-line entry points, with documentation and automated tests in the public repository.

Refer to the current project documentation for model data requirements, setup, supported workflows and limitations. External model datasets have their own access and licensing terms.

Code you can inspect.

The public repository contains the implementation, usage documentation and testing workflow. Numerical outputs depend on the selected model, reference data, input quality and local conditions; software tests do not establish a single accuracy guarantee for every coastline.

The next application.

HaoHorizon is planning an AI-assisted interface around bounded coastal workflows. The intended role of Claude is to help turn requests into reviewable configurations, explain logs and draft reports grounded in processing settings and outputs.

The scientific tools would perform the calculations, with approval before execution. The Claude API integration is in planning and evaluation; it is not a currently available feature.
